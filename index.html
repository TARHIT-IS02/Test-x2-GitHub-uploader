How to use

1
Connect GitHub

Tap “Sign in & connect”, sign in to GitHub, then generate a token with the “repo” scope. Paste it and tap “Verify”. It is remembered on this device automatically. Not sure how? See “Get your GitHub token” at the bottom.

2
Choose a repository

Pick one from your list (or type username and name), set the branch and an optional target folder such as assets/uploads, then tap “Save & continue”. No repository yet? Use “Create new repository”.

3
Select what to upload

Choose Files, a Folder or a ZIP (or drag & drop on desktop). Folder paths are kept. If a folder or ZIP has a single top-level folder, choose whether to keep or remove it.

4
Review

“Review & Push” shows the final tree, full paths and a folder browser. Remove files with the X button, edit the commit message, and fix any name clashes. Files over 100 MB are skipped.

5
Push

Everything is sent as one commit. Keep the tab open until it finishes. If something fails, tap Retry and it resumes.

6
Custom README

In Settings → Uploads, write your README.md once; it saves automatically. While “Include my README in uploads” is on, it is added to every push and used when you create a repository with “Add a README”, so no default README is made. You can switch it off per push in the Review screen. A README.md in your own selection always wins.

7
Good to know

Junk files (.DS_Store, Thumbs.db) are skipped by default. “Sign out” or “Clear saved data” removes your token from this browser. Your token is only ever sent to GitHub.

Get your GitHub token

A personal access token is a long password-like code that lets this app upload to your repositories for you. It is free, takes about a minute, and you only need to do it once.

  1. Sign in to github.com in your browser (or tap “Open GitHub & create key” in the connect dialog).
  2. Tap your profile picture (top right) → Settings.
  3. Scroll to the very bottom of the left menu and open Developer settings.
  4. Open Personal access tokens → Tokens (classic).
  5. Tap Generate new token → Generate new token (classic). GitHub may ask for your password.
  6. Give it a name in Note (for example “GitHub Uploader”) and choose an Expiration. “No expiration” means you never have to repeat this.
  7. Under Select scopes, tick the repo box. That one tick (it selects all the boxes under it) is all this app needs. Also tick workflow only if you upload GitHub Actions files (.github/workflows).
  8. Scroll down and tap Generate token.
  9. Copy the token now (it starts with ghp_). GitHub shows it only once. Paste it into the token field of this app and tap “Verify & add account”.
Shortcut: the “Open GitHub & create key” button in the connect dialog opens this page with the “repo” scope already ticked. Just add a name, scroll down and tap Generate token.
Treat your token like a password. Never share it or post it publicly. If it leaks or stops working (“Invalid or expired token”), delete it in GitHub and generate a new one.

Using an organization’s repository with single sign-on? After generating, tap Configure SSO next to the token and Authorize the organization. Prefer fine-grained tokens? Give them access to the repository with Contents: Read and write (and Administration: Read and write if you want to create repositories here).
