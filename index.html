Help & security

Your token stays in your browser. It's only sent to the GitHub API over HTTPS.

ZIP structure is yours to choose. Paths are preserved exactly; if a ZIP has one top-level folder you can keep it or remove it before uploading.

One commit. Files are pushed using their full relative paths, so GitHub displays their folders and subfolders normally.

Folders upload their contents directly to the target path — no extra wrapper folder is added. Folder picking isn't supported by some mobile browsers; use a ZIP there.
